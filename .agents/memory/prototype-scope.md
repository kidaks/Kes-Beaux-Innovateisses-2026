---
name: Monitoring prototype scope
description: Persistent safety framing for the forest-fire monitoring training prototype.
---

All stations, measurements, risk scores, and alerts in this project are educational demonstration data. This interface is not a real fire-detection or emergency-response system.

**Why:** The user requested an operator-training prototype and explicitly said its fire-risk readings should not be mistaken for real fires.

**How to apply:** Keep demo labels visible in the UI and any external notification. Never describe the app as monitoring real conditions or dispatching real emergency alerts.
